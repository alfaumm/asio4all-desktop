## 🗂️ What This App Does

Asio4all Desktop focuses on one job and does it well: protecting the text files that hold your audio configuration and export settings.

Here is the idea in plain language. Your Asio4all setup lives in a few data folders on your disk. Inside those folders are config files and export files. When a patch or an update arrives, those files get changed. Usually that is fine. Sometimes it is not, and you end up with a setup that no longer works the way it used to.

This app makes a dated copy of those files before the patch happens. So instead of one live version that can be overwritten, you end up with a small library of snapshots, each labelled with the date it was taken.

- **Dated copies** — every snapshot carries its date, so you can point to the exact moment a working setup existed.
- **Config files covered** — the settings files that define how your audio behaves are included.
- **Export files covered** — the files you generated and saved out are included too.
- **Stays on disk** — nothing is uploaded anywhere; the copies live in folders on your own computer.
- **Patch-safe** — the copy is taken before the patch, not after, so there is always a version from before the change.

## 💡 Why Dated Copies Matter

Audio setups are fussy. A configuration that took an hour of careful adjustment can be replaced by a default in seconds, and once it is gone, it is gone. Rebuilding it from memory rarely produces the same result.

A dated copy changes that situation. If something sounds wrong after an update, you do not need to remember what the settings used to be. You open the folder, find the copy from before the patch, and compare or restore. The older version is still there, untouched, with its original date on it.

This is also useful when you are experimenting. You can try a new patch, hear the difference, and decide calmly whether to keep it, because you already know a copy of the previous state exists.
